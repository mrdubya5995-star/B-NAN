This directory is populated by `npm run fetch:native` (see
`tools/fetch-native-emulators.js` and `docs/NATIVE_EMULATORS.md`) and is
NOT committed with real content -- it holds the native (non-browser)
desktop emulator binaries B-NAN bundles into its .dmg/.exe/.AppImage
builds. Empty (aside from this file and manual-drop/) until that script
has been run on a real machine.
